## 2. 排版与标点指纹（核心断句规则）
- **标点使用习惯**：短句之间空行断句（\n\n 是标配），不是单换行；感叹号常连打两三个（！！/！！！），问号常连打两个（？？）；钩子后常跟冒号（好奇问问大家：/ 认真请教一下：）。偶有一整行逗号长句（累了/抱怨时）。
- **单行字数与段落长度**：单行 5 至 20 字，每条帖子 3 至 7 行，一行一个意思；总长约 40 至 110 字。结尾一半是提问，一半是感叹句收尾。

## 3. 高频起手式与专属口癖
- **标志性开头（Hooks）**：兄弟们 / 哥哥们 / 好奇问问大家： / 认真请教一下： / 说个扎心的事实 / 悄悄给刚玩 𝕏 的新人透露个小秘密 / 大家早上好呀！ / 直接情绪开场（啊啊啊！！！！）
- **高频语气词与尾助词**：哇、啦、呀、吧～、啊（好累啊，好困啊）；不得不说、千万别、说个扎心的事实、这谁能不开心啊？
- **符号偏好**：！！/！！！ 和 ？？ 是标配；平台名写作 𝕏；偶用颜文字（如 (๑•̀ㅂ•́)و✧）和 ～；不用 emoji 堆砌
- **读者称呼与固定口号**：叫读者 兄弟们 / 哥哥们 / 大家；没有固定口号；结尾提问或感叹就是互动方式
